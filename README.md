# Country Liquors

Website for a neighborhood liquor store on Jackson St in Hayward, CA.

**Live site:** https://countryliquorshayward.com

![Country Liquors homepage](screenshot.png)

## Features

- About, product categories (beer, wine, spirits, snacks), photo gallery and reviews sections
- Live open/closed status with the current Pacific time
- Embedded Google Map and one-tap directions
- Tap-to-call button
- Responsive layout for phones and desktops

## Tech

A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step), hosted on Netlify with continuous deployment from this repository.
